## Voices 0.2.0 - MIDI learn

**New: MIDI LEARN** (ported from Decu6000) - control Voices from your MIDI controller.
- Click **MIDI LEARN** in the header, click any knob, switch or button row, move a knob or fader:
  assigned. Every control shows its CC while learn mode is on.
- Or right-click any knob > *Learn MIDI CC...* / *Clear MIDI CC*.
- Right-click a control in learn mode to clear it; right-click the MIDI LEARN button to clear all.
- Saved with your DAW project (not with patches). CC 64 stays the sustain pedal.

## Voices 0.1.0 - first release

Vocal synth, choir, vocoder, auto-tune and voice changer in one, in the Decu6000 look.

**Downloads:** Windows (x64) and Linux (x86_64), each with
- `Voices.vst3` - instrument (choir / vocal synth / vocoder from MIDI, side-chain voice input)
- `Voices FX.vst3` - insert effect for vocal tracks (auto-tune, voice changer; accepts MIDI)
- the Standalone app (microphone in, on-screen keyboard, MIDI keyboard)

**Highlights**
- Auto-tune from subtle to hard stepped "robot" tuning: key, 10 scales or MIDI notes, retune,
  amount, humanize, SUBTLE / MODERN / HARD style buttons, live pitch display.
- Voice changer: MALE / FEMALE / MIXED + one AMOUNT knob (pitch and formants move together).
- Vocoder: 8-32 bands, three carriers, AUTO mode sings your pitch with no keyboard.
- Choir oohs / aahs in the classic keyboard style, vowel vocal synth (A E I O U).
- Arpeggiator (TREM / UP / DOWN / RANDOM, 1-4 octaves, tempo synced), chorus, delay, reverb.
- 13 factory patches; user patches as `.voicespatch` files.

Install notes are in the INSTALL file inside each download. Free software (AGPL-3.0-or-later).
